환경
python 버전 : Python 3.14.3 (*공식 사이트에서 python 설치했기 때문에 brew로 python을 설치할 경우 추가 라이브러리 설치 해야 함)
선택 사항 : venv 활용 (라이브러리 격리, 추천 환경)


필수 설치 라이브러리
pip install requests
pip install customtkinter 
pip install pillow -> 아이콘 적용
pip install PyInstaller -> 빌드 용

한 번에 설치 : pip install requests customtkinter pillow PyInstaller


코드로 실행
python main.py


빌드 명령어
window : python -m PyInstaller --windowed --name SCIM_win --distpath dist_win --workpath build_win --icon=netskope_app.ico --add-data "netskope.jpg;." main.py --onefile --clean
mac : python3 -m PyInstaller --windowed --name SCIM_mac --distpath dist_mac --workpath build_mac --icon=netskope_app.icns --add-data "netskope.jpg:." main.py --onefile --clean


프로그램 위치
Window : dist_win > SCIM_win 
Mac : dist_mac > SCIM_mac 

※특이 사항※
1. 맥용 소프트웨어는 메일로 옮기면 깨지는 현상이 있음. 이 경우는 다시 위의 설명대로 라이브러리 설치하고 빌드 진행하면 됨
2. 맥 보안으로 인해서 실행 안되는 경우 "SCIM_mac을 열지 않음 - ~~ 개인의 정보에 침입할 수 있는 악성 코드가 없음을 확인할 수 없습니다" -> 이 경우는 시스템 설정 > 개인정보 보호 및 보안 > 하단에 그래도 허용 
3. 맥용 소프트웨어는 맥OS에서 빌드해야 함
4. 윈도우 소프트웨어는 윈도우OS에서 빌드해야 함
